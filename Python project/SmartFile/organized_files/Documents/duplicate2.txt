REVISION REFERENCE CHEAT SHEET: CORE ALGORITHMS
===============================================

Algorithm Complexities:
- Quicksort: Average O(n log n), Worst O(n^2), In-place.
- Mergesort: Best, Average, Worst O(n log n), O(n) space.
- Binary Search: O(log n) time, requires sorted sequence.
